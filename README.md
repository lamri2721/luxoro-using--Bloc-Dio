✨ LUXORA — Luxury Fashion Store App

A premium Flutter CRUD application built using Bloc State Management and the Dio package, designed with a modern luxury shopping experience inspired by high-end fashion brands.

LUXORA allows users to browse, create, update, and delete luxury fashion products using a public REST API with elegant UI animations, responsive layouts, and clean architecture.

📌 Project Overview

LUXORA is a fully functional CRUD-based Flutter application developed to simulate a modern luxury fashion e-commerce platform.

The application demonstrates:

API integration using Dio

Bloc state management

Clean software architecture

Real-time UI updates

Error handling and loading states

Responsive premium UI design

The application uses FakeStoreAPI as a backend service for handling products.
